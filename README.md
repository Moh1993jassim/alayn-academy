# أكاديمية الاستحصال

البرنامج التدريبي للمستحصلين — قسم الترويج والاستحصال، لجنة تطوير المستحصلين، مؤسسة العين للرعاية الاجتماعية.

أربعة مسارات في رابط واحد: **المالي، الكفالة، المخازن، صناديق الصدقات**. لكل مسار وحداته واختباره وشهادته. الدخول باسم المندوب ورقم هاتفه، ونتائج كل متدرب تصل لحظياً إلى Google Sheet القسم.

## مكونات النظام

| الجزء | المكان | الكلفة |
|---|---|---|
| الموقع | GitHub Pages (هذا المستودع) | مجاني |
| سجل المندوبين والنتائج | Google Sheet | مجاني |
| الربط بين الموقع والشيت | Google Apps Script (`backend/Code.gs`) | مجاني |
| فيديوهات الشرح | YouTube (غير مدرج) | مجاني |

## التشغيل لأول مرة

### 1) الموقع منشور ✔
**الرابط:** https://moh1993jassim.github.io/alayn-academy/

- يعرض GitHub Pages فرع `gh-pages`، وأي تعديل تحفظه على `main` يُنشر إليه تلقائياً خلال دقيقة أو دقيقتين (ملف `.github/workflows/publish.yml`). عدّل دائماً على `main`.
- لمتابعة النشر: تبويب **Actions** في المستودع.

> المستودع **Public** حتى يعمل GitHub Pages المجاني. لا يحتوي الكود على أي اسم أو رقم هاتف؛ القائمة محفوظة في الشيت فقط.

### 2) إنشاء سجل القسم (Google Sheet)
يُفضَّل أن يكون بحساب Google خاص بالقسم، لا بحساب شخصي.

1. أنشئ Google Sheet جديداً باسم «سجل أكاديمية الاستحصال».
2. Extensions ← Apps Script، واحذف المحتوى الموجود.
3. الصق محتوى `backend/Code.gs` كاملاً، ثم احفظ.
4. من القائمة أعلى المحرر اختر الدالة **setup** ثم **Run**، ووافق على الصلاحيات. ستُنشأ الأوراق تلقائياً:
   - **المندوبون**: الاسم الكامل، رقم الهاتف، الفرع، المكتب، المدرب، فعّال.
   - **المدربون**: اسم المدرب، الفرع. تظهر هذه القائمة للمتدرب عند أول دخول إذا لم يُحدد مدربه في ورقة المندوبين.
   - **المتدربون**: صف لكل من دخل، يتحدث تلقائياً.
   - **سجل_الاختبارات** و**سجل_النشاط**.
   - **لوحة_القسم**: إحصاءات حسب الفرع وحسب المدرب.
5. الصق قائمة المندوبين في ورقة «المندوبون» بالترتيب أعلاه، أو استخدم قالب الإكسل المرفق.
6. Deploy ← New deployment ← النوع: **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - ثم Deploy، وانسخ رابط **Web app URL**.

### 3) ربط الموقع بالسجل
افتح `config.js` في المستودع (أيقونة القلم للتعديل) وضع الرابط:

```js
API_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

ثم Commit. من هذه اللحظة لا يدخل إلا المسجّلون في ورقة «المندوبون».

## إضافة فيديو لوحدة
في `config.js` داخل `VIDEOS` سطر لكل وحدة، وعليه اسمها. استبدل الرابط فقط ثم Commit، ويُنشر خلال دقيقتين.

ثلاثة أنواع، بالترتيب حسب الأفضلية:

```js
m1: { mp4: 'assets/videos/m1.mp4', poster: 'assets/videos/m1.jpg' },          // ملف مرفوع مع الموقع
m2: { yt: 'https://youtu.be/XXXXXXXXXXX', checks: [ { at: 95, q: 'السؤال؟', o: ['خيار','خيار'], a: 0 } ] },
m3: { ig: 'https://www.instagram.com/reel/XXXX/', sec: 90 }
```

- **ملف مرفوع مع الموقع (الأضمن):** ارفع ملف MP4 إلى مجلد `assets/videos` (Add file ← Upload files). يعمل على كل الأجهزة، ولا يسمح بتجاوز جزء لم يُشاهَد، ويحدّ السرعة بـ 1.5×. يُفضّل أن يكون الملف أقل من 50 ميغابايت (H.264، دقة 720p).
- **YouTube:** تُحتسب الثواني المشاهدة فعلاً، والتقديم السريع لا يُحتسب. ارفع الفيديو «غير مدرج» (Unlisted) مع السماح بالتضمين. إذا تعذّر التشغيل تظهر للمتدرب رسالة برمز الخطأ مع «إعادة المحاولة» و«شاهده على YouTube».
- **Instagram:** لا يمكن قياس المشاهدة؛ يُفتح المقطع ويُفعَّل التأكيد بعد مدته (`sec`).
- أسئلة التحقق (`checks`) تعمل مع الملف المرفوع ومع YouTube: `at` الثانية التي يظهر عندها السؤال، و`a` رقم الجواب الصحيح يبدأ من 0. الجواب الخاطئ يعيد المقطع 30 ثانية.
- اختبار المسار لا يُفتح إلا بعد إتمام وحداته الأساسية.

## الأرقام المتحركة
- **صفحة الدخول:** الرقم الكبير من «عملنا بالأرقام» في موقع المؤسسة، ويُعدَّل من `IMPACT` في `config.js`.
- **بعد ربط الشيت:** تظهر أرقام حيّة من سجل القسم (المتدربون، الشهادات، الوحدات المنجزة، الفروع)، وعدد المتدربين في كل مسار، وترتيب الفروع. تتحدث كل دقيقة، ولا تكشف أي اسم أو رقم هاتف.

## تحديث بعد التعديل على Code.gs
Deploy ← Manage deployments ← تعديل (القلم) ← Version: **New version** ← Deploy. يبقى الرابط نفسه.

## الأمان والخصوصية
- أرقام الهواتف لا تصل إلى المتصفح إطلاقاً؛ التحقق يتم داخل Apps Script.
- بعد 8 محاولات دخول خاطئة يُقفل الرقم 15 دقيقة.
- كل متدرب يحمل رمز دخول موقّعاً صالحاً 45 يوماً، ولا يُقبل أي تسجيل نتيجة بدونه.
- إذا انقطع الإنترنت تُحفظ النتائج على الجهاز وتُرسل تلقائياً عند عودة الاتصال.
